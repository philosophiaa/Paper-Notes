01 Issues with Your Internet Provider｜网络服务问题

描述具体问题，并自然表达不满与沮丧

Describing Issues｜描述服务问题
The service just isn’t reliable.
这项服务就是不可靠。
We have problems downloading things.
我们下载东西时遇到了问题。
It’s difficult to get the support we need.
很难获得我们需要的支持。
It takes ages to get a response.
等待回复需要很长时间。
reliable 可靠的download 下载support 技术支持response 回复／响应take ages 花很长时间

核心结构

have problems + V-ing：We have problems downloading things.

It’s difficult to + 动词原形：It’s difficult to get support.

It takes ages to + 动词原形：It takes ages to get a response.

Saying How We Feel｜表达感受和不满
We’re not so happy with our current service.
我们对目前的服务不太满意。
The speed is driving us crazy.
网速慢得让我们很抓狂。
It can be pretty frustrating.
这确实令人相当沮丧。
It’s always so unreliable.
它总是很不可靠。
frustrating vs. frustrated：The service is frustrating（服务令人沮丧）；I’m frustrated with the service（我感到沮丧）。always 表示“总是”，never 表示“从不”。

02 Comparing Packages｜比较服务套餐

比较套餐特点、性价比与数字，并说明是否满足需求

Package Features｜套餐特点
Elektra is the basic package.
Elektra 是基础套餐。
Foto is our premium package.
Foto 是我们的高级套餐。
The premium package is a high-speed, high-quality service.
高级套餐提供高速、高质量的服务。
The basic package is very good value for money.
基础套餐性价比很高。
I think the basic package will meet your needs.
我认为基础套餐能够满足你的需求。
basic package 基础套餐premium package 高级套餐high-speed 高速的good value for money 性价比高meet your needs 满足需求
Both, Neither & Differences｜两者比较
Both L1 and L2 are high-speed packages.
L1 和 L2 都是高速套餐。
Neither package is really good value for money.
两种套餐的性价比都不算高。
Are there any differences between the two packages?
这两个套餐之间有什么区别吗？
The two packages are pretty similar.
这两个套餐相当相似。
固定搭配：similar to · different from · differences between A and B。both = 两者都；neither = 两者都不。
Large Numbers｜大数字
数字英文读法
105,000one hundred and five thousand
1,000,000one million
1,250,000one million two hundred and fifty thousand
4,000,000 yen per yearfour million yen per year
注意：具体数字后面的 hundred、thousand、million 不加 -s：three million，不说 three millions。网速单位 Mbps = megabits per second。

03 Asking About a Service｜询问服务内容

确认技术支持、响应时间、上门服务和付款方式

Service Features｜服务特点
There’s a 24-hour help line.
有 24 小时服务热线。
That’s covered in the service plan.
这包含在服务计划中。
We can send someone out to you.
我们可以派人上门为您服务。
We have a 12-hour response time.
我们的响应时间是 12 小时。
You can set up a regular payment.
您可以设置定期付款。
You can get technical support any time.
您可以随时获得技术支持。
Questions to Ask｜询问服务细节
What if we have problems with the internet?What’s the response time?Is your help line open 24 hours?Is technical support included?Can you send someone out to us?How do we pay?
Service Conversation｜服务咨询对话

Customer: What if we have problems with the internet?

Provider: You just call our help line and we send someone out. That’s covered in the service plan.

Customer: What’s the response time?

Provider: Same day.

Customer: You mean it’s a 24-hour response time?

Provider: Yes. For an extra 60,000 per month, we can send someone out in six hours.

Customer: Is your help line open 24 hours, too?

Provider: That’s right. If you set up a regular payment, we take the money at the end of each month.

04 Terms and Conditions｜合同条款

提出假设、澄清含义，并确认合同许可和义务

When, If & What If｜条件表达
When you have a problem, you just call our help line.
当／每次遇到问题时，拨打服务热线。when 强调发生时或每次发生时。
If we have a question, we can call any time.
如果有问题，可以随时打电话。if 强调假设条件。
What if we need technical support?
如果我们需要技术支持怎么办？
Using Mean｜澄清和修正
You mean there’s a 24-hour response time?
你的意思是响应时间为 24 小时吗？
It’ll be here in 24 hours. Sorry, I mean 48.
会在 24 小时内送到。抱歉，我是说 48 小时。
I see what you mean.
我明白你的意思。
Contract Details｜合同细节
You can cancel any time.
您可以随时取消。
You’ll need to give us 30 days’ notice.
您需要提前 30 天通知我们。
Are we able to change packages?
我们可以更换套餐吗？
You can upgrade to a premium package.
您可以升级到高级套餐。
You have to wait for the contract to expire.
您必须等到合同到期。
Permission & Obligation｜许可与义务
功能结构例句
许可be allowed to / can / be able to + 动词原形Are we allowed to change packages?
Can we cancel the contract?
Are we able to upgrade any time?
义务need to / have to + 动词原形Do we need to give you notice?
We have to wait for the contract to expire.
cancel 取消give notice 提前通知upgrade 升级contract 合同expire 到期

05 Teacher’s Feedback｜课堂词汇与老师反馈

套餐选择、性价比、合同期限和技术支持相关的课堂纠错

Class Vocabulary｜课堂补充词汇
cheat day
放纵日；健身或饮食计划中暂时放宽饮食限制的一天。
allergy / allergies
过敏；过敏症。例：I have a seafood allergy.
seafood
海鲜，通常是不可数名词。
crab / crabs
螃蟹。
common food
常见食物；更自然也可说 common dish（常见菜品）。
fruit juice
果汁。
pork
猪肉，不可数名词。
binge-watching
连续追剧。例：I spent the weekend binge-watching a TV series.
Good Things｜表现良好的词句
I’d like to choose the premium package.Another important factor is …What if I have …?What’s the response time?upgrade 升级contract 合同technical problems 技术问题
Choosing a Package｜说明套餐选择
需要修改推荐表达要点
I’d like to choose the premium package is that one reason is the speed of this package is faster than the basic package.I’d like to choose the premium package. One reason is that its speed is faster than that of the basic package.避免两个完整句子直接拼接；that of 代替重复的 the speed。
The data of premium package is unlimited per month.The premium package includes unlimited data each month.include unlimited data 更自然。
The high speed and big data is important for me.High speed and a large data allowance are important to me.两个并列主语用 are；通信套餐常说 data allowance。
I think it worth it for its better quality in the speed and data.I think it is worth it because of the better speed and larger data allowance.worth it 前需要 be 动词：it is worth it。
worth 的常用搭配：worth it（值得）· worth the price（值这个价格）· worth the money（物有所值）。
To Say / To Do｜套餐表达练习
I prefer the premium package.
我更喜欢高级套餐。
The premium package would be worth the money.
高级套餐会物有所值。
There’s only a slight difference in price.
价格方面只有一点差异。difference in price。
Technical Problems｜技术问题
What if I have technical problems?
如果我遇到技术问题怎么办？复数 problems 前不加 a。
What if I have a technical problem?
如果我遇到一个技术问题怎么办？单数 problem 前需要 a。
Contract Length｜询问合同期限
What’s the contract duration?
合同期限是多久？
What’s the duration of the contract?
合同的期限是多久？
What’s the contract period?
合同期是多久？
How long does the contract last?
合同持续多久？不能说 What’s the contract last?
Consider & Clarify｜考虑与澄清
I will consider upgrading.
我会考虑升级。consider 后接动词 -ing。
You mean I can call you at any time of day?
你的意思是我一天中任何时候都可以打电话给你？
I mean, I want to ask for an upgrade.
我的意思是，我想申请升级。
I’d like to clarify the technical support arrangements.
我想确认技术支持安排。clarify 后直接接宾语，不加 about。
本次重点：worth it · difference in price · consider doing · a technical problem / technical problems · How long does the contract last?

06 Complete Role-play｜综合商务对话

代表公司联系网络服务商，从问题描述到合同确认

A. Describing Problems｜描述问题

We’re not so happy with the service because it isn’t reliable. We often have problems downloading things, and the speed is driving us crazy. It’s difficult to get the support we need, and it takes ages to get a response.

B. Comparing Packages｜比较套餐

I’d like to know more about the premium package because our company needs a high-speed internet service. I think it offers better value for money because it includes high-speed internet and 24-hour technical support. I think it’s worth it because the better service can improve our work efficiency.

C. Asking About Service｜询问服务

I’d like to learn more about the technical support service, especially the response time. What is the response time? Is technical support included in the service plan?

D. Asking About Contract Terms｜询问合同条款

I’d like to know more about the contract terms, especially the contract period and cancellation policy. If we cancel early, do we need to pay an additional fee? Can we upgrade our package if we need faster internet in the future?

E. Ending the Conversation｜结束对话

No, that’s all. Thank you for the information. I will consider the premium package.
