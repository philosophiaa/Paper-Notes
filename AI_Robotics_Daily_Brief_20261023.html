一、机器人与具身智能 60%

01 ｜ 预印本

UC Berkeley × NVIDIA：把 Agent、世界模型和 VLA 合成一个系统

AW-0：Agentic World Action Models ｜ 重要性：★★★★★

论文：Agentic World Action Models

公开日期：10 月 21 日提交，22 日进入 arXiv 更新列表。
研究机构：加州大学伯克利分校、NVIDIA（官网）、宾夕法尼亚大学。
重要研究者：Ken Goldberg、Yuke Zhu、Danfei Xu、Linxi Fan、Trevor Darrell——这是一支在机器人学习、计算机视觉和具身智能领域有较强研究积累的团队。
发表状态：arXiv 预印本，尚未确认正式会议接收。

它解决什么问题？

现在的 VLA 能根据图像和指令生成动作，世界模型还能预测动作之后的画面。但让机器人连续完成复杂任务，仍然很困难。比如整理厨房，机器人需要依次打开柜门、拿出杯子、移动餐具——它不仅要生成动作，还需要知道什么时候该调用已经学会的技能。

AW-0 的做法是让一个模型同时生成三类内容：技能程序 + 未来画面 + 机器人动作。其中，技能程序相当于一份可以重复使用的操作流程。模型既可以直接输出动作，也可以在满足条件时调用已有技能。

实验结果：在 RoboTwin 2.0 基准上，AW-0 的平均成功率达到 50.7%，高于所比较的 VLA 和世界动作模型。在八项真实双臂机器人任务中，平均任务评分达到 71.1%，相比表现最好的对照模型提高 25.1 个百分点。但在随机背景和环境变化较大的测试中，默认模型的成功率明显下降，说明泛化仍是难题。arXiv

影响分析：这篇论文很值得关注，因为它尝试把三个原本相对独立的模块连接起来：Agent 负责组织技能，世界模型负责预测，动作模型负责执行。未来通用机器人可能不仅需要一个强大的 VLA，还需要能够不断积累和调用的技能库。
项目主页：AW-0
02 ｜ 预印本

密歇根大学：世界模型先摸清物体特性，再进行预测

PhysiCalWorld：In-Context Physics Calibration for World Models ｜ 重要性：★★★★★

论文：PhysiCalWorld

研究机构：密歇根大学。
重要研究者：Nima Fazeli、Joyce Chai。Nima Fazeli 的研究涉及机器人操作、接触动力学和学习型控制，这篇工作与其研究方向高度相关。
发表状态：10 月 21 日提交的预印本。

它解决什么问题？

假设机器人要推动一个盒子——两个盒子外观看起来完全一样，但一个里面装满铁块，另一个是空的。如果世界模型只看图像，很难准确预测同样的推力会让盒子移动多远。

PhysiCalWorld 提出一个办法：先让机器人进行少量探索性动作，观察物体的反应，再根据这些反应调整世界模型的预测。例如，先轻轻推一下盒子，如果盒子几乎不动，模型就能从这段交互中推断出一些有关质量、摩擦等物理特性的信息。这些信息被压缩成一个表示物理特性的 Token，供后续预测使用——不需要重新训练整个世界模型，也不需要提前知道精确的质量和摩擦系数。

实验结果：研究在四类具有不同物理变化的环境中进行测试，包括物体质量分布、关节阻尼和碰撞能量损失等变化。作者报告，PhysiCalWorld 能改善多步预测精度，并提高利用视觉预测进行规划的成功率。arXiv

影响分析：这项研究与学习型 MPC 有很直接的联系。传统 MPC 需要动力学模型，而真实环境中的摩擦、质量等参数经常不准确。PhysiCalWorld 提供了一种可能性：机器人先通过交互估计当前环境的物理特性，再利用更新后的世界模型进行滚动预测和规划。它的核心价值不是取代 MPC，而是让预测模型更适应当前环境。
项目主页：PhysiCalWorld
03 ｜ 预印本

蚂蚁集团：世界模型预测接触力，传统控制器负责执行

CW-WAM：Contact-Wrench World Action Model ｜ 重要性：★★★★★

论文：CW-WAM

研究机构：蚂蚁集团（官网）。
作者：Houzhu Ding、Xinda Qi、Luqi Wang、Ming Yang。
发表状态：10 月 21 日提交的预印本。

它解决什么问题？

传统 VLA 通常输出机械臂应该移动到什么位置，但很多任务不仅需要控制位置，还需要控制接触力。例如，把一个插头插进插座——如果只控制位置，机器人可能持续向前推动，结果插头已经卡住，机械臂却还在用力。

CW-WAM 让模型同时预测：未来画面、机械臂动作，以及接下来应该产生的接触力。然后将预测的接触力交给导纳控制器，根据实际测量到的力调整机器人运动。

实验结果

方形插销插入25%70%
电源适配器插入40%95%

系统采用快慢结合的控制架构：世界模型负责较慢的动作规划；导纳控制器以 20Hz 进行力反馈修正；底层机器人控制器以 1kHz 执行平滑运动。arXiv

为什么重要：这项研究很好地说明了，VLA 和世界模型不一定需要直接控制每个关节。学习模型负责预测合理的动作与接触力，传统控制器负责根据实时反馈执行——既保留了学习模型处理复杂任务的能力，也利用了经典控制处理物理约束和实时反馈的优势。
影响分析：对精密装配、插拔、打磨和其他接触密集型任务，这是一条具有实际工程价值的路线。
项目主页：CW-WAM
04 ｜ 预印本

中山大学等：强化学习开始针对机器人长任务的薄弱环节训练

AtomicRL：Atomic Reinforcement Learning for Long-Horizon Robotic Manipulation ｜ 重要性：★★★★★

论文：AtomicRL

研究机构：中山大学、京东探索研究院、香港理工大学等。
主要作者：Likui Zhang、Zhe Zhu、Zhihao Zhan 等。
发表状态：10 月 21 日提交的预印本。

它解决什么问题？

假设机器人要完成一个任务：打开抽屉 → 拿出杯子 → 关上抽屉 → 把杯子放到桌上。如果最后一步失败，传统强化学习可能只知道整个任务失败了，却不容易判断前面哪些动作其实已经做对。

AtomicRL 将长任务拆成更小的操作单元，重点解决两个问题：

一是奖励归因。尽量避免某一步失败产生的错误学习信号影响已经完成的其他步骤。二是训练重点。哪个子任务最不熟练，就让机器人更多地练习哪个子任务。

实验结果：在 LIBERO-LONG 上，相比 PPO，两个 VLA 架构分别提高 3.6 和 4.0 个百分点。在 CALVIN ABC-D 上，完整任务成功率最高提高 9.5 个百分点。结合 Real2Sim2Real 流程后，真实机器人任务表现平均提高 21.3%。arXiv

影响分析：VLA 预训练让机器人获得基础技能，强化学习则负责进一步提高任务成功率。AtomicRL 表明，强化学习的价值不仅是让机器人不断试错，还在于识别任务瓶颈，并有针对性地改进策略。
05 ｜ 预印本

上海交大：让 VLA 只指定关键身体位置，全身控制交给专门模型

SP-HLM：Sparse-Pose-Driven Humanoid Loco-Manipulation ｜ 重要性：★★★★★

论文：SP-HLM

研究机构：上海交通大学、香港大学、摩尔线程。
重要研究者：Yao Mu。
发表状态：10 月 21 日提交的预印本。

它解决什么问题？

人形机器人拥有大量关节。如果让 VLA 直接输出所有关节的动作，模型不仅要理解任务，还要学会如何协调全身运动、保持平衡。

SP-HLM 提出：VLA 不必直接控制全身，只需要指定几个关键身体部位应该到哪里——具体包括骨盆、两个手腕和两个脚踝，共五个关键位姿。随后，运动生成模型根据这些目标补全全身动作，再由全身运动跟踪策略执行。

实验结果：论文报告，运动生成速度达到对照模型的 1.45 倍。在八项仿真人形机器人移动操作任务中，整体成功率为 52.75%，高于论文比较的关节空间和动作 Token 方法。研究还进行了四项真实机器人任务验证。arXiv

影响分析：这项研究反映了一个重要方向：VLA 负责表达任务目标，运动生成模型负责协调身体，底层控制器负责稳定执行。相比让一个模型直接完成所有事情，分层架构可能更容易利用已有的人形机器人运动控制技术。
项目主页：https://sp-hlm.github.io/
06 ｜ 预印本

斯坦福：看一段人类视频，自动生成数千条机器人训练数据

Real2Sem2Real：从人类视频到机器人模仿学习数据 ｜ 重要性：★★★★★

论文：Real2Sem2Real

研究机构：斯坦福大学、苏黎世联邦理工学院。
重要研究者：Monroe Kennedy III。
发表状态：10 月 20 日提交，已投稿 IEEE，尚未确认接收。

它解决什么问题？

假设你拍了一段人类把杯子放到咖啡机上的视频。传统模仿学习通常需要大量机器人遥操作数据，而且，训练时使用的是某个杯子，换一个形状不同的杯子，机器人可能又需要重新学习。

Real2Sem2Real 尝试从一段普通 RGB 视频中恢复物体运动，再把这些动作迁移到不同形状的同类物体上——例如，把原来杯子的抓取方式迁移到其他杯子，同时调整放置位置，使其适应不同咖啡机的托盘。随后利用 Isaac Sim 或 MuJoCo 自动生成机器人训练轨迹。

实验结果：研究报告，使用一段人类示范视频，可以在约两小时内生成超过 2000 条机器人训练轨迹。研究在 xArm7 和 Franka Panda 两种真实机械臂、四项任务上验证了训练效果：使用这些生成数据训练的 VLA，在测试任务中达到或超过部分遥操作数据训练的对照策略。arXiv

影响分析：这项研究解决的是机器人训练数据成本问题，展示了如何将人类视频、三维重建、语义理解和物理仿真结合起来。但需要注意，系统仍需要物体扫描、场景构建和轨迹验证，并不是随便上传一段视频就能自动训练出通用机器人。
项目主页：Real2Sem2Real

07 ｜ NeurIPS 2026

NeurIPS 2026：让 Agent 的长期记忆更稳定

PreCoMem：Predictive Cognitive Memory for Self-Evolving Long-Term Dialogue Agents ｜ 重要性：★★★★☆

论文：PreCoMem

主要作者：Jian Zhong、Zeyu Liu、Pingchuan Cao 等。
发表状态：已接收 NeurIPS 2026 ｜ 学术认可度：高。

它解决什么问题？

长期运行的 Agent 需要保存大量历史信息。但一个实际问题是：用户偶尔说了一句话，Agent 应不应该立刻修改长期记忆？如果每次都修改，记忆容易受到噪声影响；如果一直不修改，又无法适应真实变化。

PreCoMem 将记忆更新分成三种情况：保持原有记忆、暂时记录不确定信息、修正已经过时的信息。系统通过语义差异、信息矛盾程度和检索可信度判断应该采用哪种方式。

实验与影响：作者在 LoCoMo、LongMemEval-S 等长期记忆基准上报告了优于所比较方法的表现。arXiv

影响分析：Agent 的长期记忆不只是把历史记录全部存下来，更重要的是判断哪些信息可信、哪些已经发生变化。这一能力未来也可能帮助机器人管理长期任务状态，但目前论文主要验证的是对话 Agent。
开源代码：PreCoMem GitHub
08 ｜ 预印本

北京大学等：让大模型并行思考时，真正走不同的推理路线

DPT：Diverse Parallel Thinking ｜ 重要性：★★★★☆

论文：Parallel Thinking for Large Language Model with Path Diversity

主要作者：Jiaru Qian、Yihong Dong、Xue Jiang、Zhi Jin、Ge Li 等。
发表状态：10 月 21 日提交的预印本。

它解决什么问题？

现在的大模型可以同时生成多条推理路径，再比较答案。但研究发现，即使同时生成多个答案，模型也可能反复采用非常相似的思路，这样并没有真正增加探索范围。

DPT 在强化学习过程中鼓励不同推理路径保持差异。简单说，就是：不要让模型同时想五遍同一个办法，而是尽量让它尝试五种不同的办法。

实验与影响：作者在多个推理基准上报告了相比现有并行推理方法更好的表现。arXiv

影响分析：这对复杂 Agent 规划具有潜在价值。例如，机器人面对一个难以完成的任务时，可以考虑不同操作顺序，而不是反复生成相似计划。不过，该研究尚未直接验证机器人控制效果。
开源代码：DPT GitHub
09 ｜ 安全评估

OpenAI Agent 安全评估：外部研究人员发现监控机制存在漏洞

10 月 22 日 ｜ 重要性：★★★★★
公司：OpenAI（官网） ｜ 评估机构：METR、Redwood Research。
来源：Reuters 10 月 22 日报道

发生了什么？

两家外部 AI 安全研究机构在今年 7 月 21 日至 8 月 11 日期间，对 OpenAI 的内部 Agent 监控系统进行了测试，并发现了多个安全问题。其中一个漏洞可能让 Agent 的大量操作无法被正常监控；另一个问题可能使 Codex Agent 绕过部分权限限制，以用户的完整权限执行操作。

OpenAI 表示，影响生产环境安全机制的相关漏洞已经修复，但外部研究机构尚未独立验证修复结果。

为什么重要：Agent 与普通聊天模型最大的区别是，它可以真正执行操作。因此，安全问题不仅是模型会不会生成错误内容，还包括：它会不会执行错误操作，以及外部系统能不能及时发现并阻止。
影响分析：随着 Agent 能够访问文件、数据库和生产系统，独立监控、权限隔离和执行审计会越来越重要。这也给未来的机器人 Agent 提出了类似要求：不能只依赖模型自己判断行为是否安全。

五、本期综合判断

1. VLA 与传统控制正在形成更清晰的分工。 今天的 CW-WAM 和 SP-HLM 非常有代表性：CW-WAM 让世界模型预测接触力，再利用导纳控制完成实时反馈；SP-HLM 则让 VLA 生成关键身体目标，由专门的运动生成和全身控制模型执行。这说明一个趋势——机器人不一定需要一个模型直接控制所有关节，高层学习模型与专门控制模块的结合，仍然是一条重要路线。

2. 世界模型开始更加重视真实物理规律。 PhysiCalWorld 关注质量、摩擦和阻尼等隐藏物理特性，CW-WAM 关注实际接触力。这些研究都在尝试解决一个问题：世界模型不能只预测看起来合理的画面，还需要预测符合真实物理规律的结果。这将直接影响世界模型能否用于 MPC、机器人规划和强化学习训练。

3. Robot Learning 的重点正在从模仿动作转向持续改进。 Real2Sem2Real 尝试降低训练数据成本，AtomicRL 则尝试让机器人发现自己最不擅长的任务步骤再集中训练，AW-0 进一步研究如何把已经学会的技能组织起来供后续任务复用。三者代表了机器人学习过程中的不同环节：获取数据 → 学习基础技能 → 强化薄弱能力 → 复用已有技能。
