02 ｜ CoRL 2026 Oral

UC Berkeley：人形机器人动作训练成本降低超过 1000 倍

SuperMimic ｜ 重要性：★★★★★

论文：SuperMimic: Scaling Humanoid Whole-Body Control with One Differentiable World Model

研究机构：加州大学伯克利分校
重要研究者：Pieter Abbeel（机器人强化学习领域的代表性研究者）、Koushil Sreenath（长期研究机器人动力学、双足运动和全身控制）。
第一作者：Qiayuan Liao
论文出处：arXiv:2610.28480 ｜ 发表状态：CoRL 2026 Oral
学术认可度：很高。CoRL 是机器人学习领域的重要顶级会议，Oral 表示论文获得口头报告展示机会。

它解决什么问题？

现在训练人形机器人完成大量人类动作，往往需要很多 GPU。传统方法通常让机器人在物理仿真器中反复尝试动作，通过强化学习不断调整策略。SuperMimic 换了一种方式：先学习一个机器人动力学世界模型，再让机器人在这个模型里进行大量虚拟训练。因为这个世界模型支持梯度传播，训练策略时可以更直接地利用预测结果，而不必完全依赖传统强化学习的反复试错。

实验结果

指标SuperMimic
训练硬件1 张 H100 GPU
达到对照模型性能所需时间约 3 小时
GPU 计算时间相比对照方法减少超过 1000 倍
测试动作数量129,514
训练 9.8 小时后的失败动作数0
真实机器人验证Unitree G1

研究还展示了真实 G1 执行多种复杂动作的能力。arXiv

需要注意：两种方法使用的 GPU 型号和训练数据规模不同，不能把计算量差距完全理解为同等条件下的算法加速。另外，129,514 个动作属于训练动作集合，不能据此认定机器人对所有新动作都能零失败泛化。
为什么重要：这是本期最值得关注的 Robot Learning 论文之一。如果这种方法能够在更多机器人平台上复现，人形机器人训练成本可能明显下降。过去需要大规模 GPU 集群完成的动作训练，未来可能用少量 GPU 就能实现。
项目主页：SuperMimic
03 ｜ 预印本

Amazon：把世界模型、动作生成和语言记忆放进同一个模型

UniWALM ｜ 重要性：★★★★★

论文：UniWALM: Unified World Action Language Model for Embodied Robot Control

研究机构：Amazon、布朗大学、东北大学等。
重要研究者：Srinath Sridhar，主要研究机器人视觉、三维感知和操作学习。
第一作者：Rahul Sajnani
论文出处：arXiv:2610.28626 ｜ 发表状态：10 月 20 日提交的预印本，尚未确认会议或期刊接收。
学术认可度：待同行评审。

它解决什么问题？

假设机器人要完成一个任务："找到刚才放进抽屉里的钥匙。"机器人不仅需要知道怎么打开抽屉，还需要记得钥匙之前放在哪里。现在很多 VLA 只根据当前图像和指令生成动作，如果任务持续很长时间，机器人可能忘记之前做过什么。

UniWALM 提出：让机器人在生成动作的同时，生成对任务进度的语言描述——例如"当前任务：寻找钥匙；已经完成：检查桌面；下一步：打开左侧抽屉"。这些文字会在下一次动作生成时重新输入模型，相当于形成一个简短的工作记忆。与此同时，模型还学习预测未来的视频画面。

实验结果

模型设置（真实机器人寻找物体任务）成功率
不使用语言记忆的对照模型11.1%
UniWALM61.1%

在 RMBench 的记忆相关任务中，UniWALM 达到 34.5% 的成功率，高于论文比较的相关基线。arXiv

为什么重要：UniWALM 展示了一种新的模型设计——世界预测、动作生成和语言记忆不一定需要三个独立模型，也可以在一个统一模型中共同学习。不过，统一架构是否比模块化架构更适合大规模机器人部署，还需要更多实验。
项目主页：UniWALM
04 ｜ 预印本

CMU + NVIDIA：只看几秒钟人类动作，就能训练灵巧手技能

AdaDex ｜ 重要性：★★★★★

论文：Learning Adaptable Dexterous Skills via Hybrid Dexterous Mimicking

研究机构：卡内基梅隆大学、NVIDIA。
重要研究者：Katerina Fragkiadaki（长期研究机器人学习、视觉和物理世界建模）、Shubham Tulsiani（主要研究三维视觉、机器人操作和从视觉数据中学习物理交互）。
第一作者：Yuxuan Kuang
论文出处：arXiv:2610.28628 ｜ 发表状态：arXiv 预印本，尚未确认正式接收。

它解决什么问题？

人类拿起锤子时，知道应该握住手柄，而不是抓住锤头。但机器人强化学习通常只关心最终任务有没有成功——如果没有额外约束，机器人可能学会一些很奇怪、但在仿真中能够完成目标的抓取方式。

AdaDex 把两种训练方式结合起来：模仿学习负责教机器人怎么像人一样操作，强化学习负责让它适应新的物体位置和姿态。研究只需要每项技能几秒钟的人类动作示范，就可以在仿真中扩展出大量训练场景。

实验结果：机器人学会了功能性抓取、手内调整物体姿态、抛接物体等技能。研究还展示了跨仿真器迁移，以及向真实机器人系统迁移的能力。arXiv

影响分析：这条路线的价值是降低灵巧手技能训练对大规模人工遥操作数据的依赖。但"几秒钟示范"不代表整个训练只需要几秒钟，后续仍需要大量仿真训练。
项目主页：AdaDex
05 ｜ 预印本

中科院：世界模型不仅预测画面，还要预测触觉

Physical Canvas ｜ 重要性：★★★★★

论文：Physical Canvas: A Vision Tactile World Model for Robot Policy Evaluation and Learning

研究机构：中国科学院自动化研究所、新加坡国立大学、Anyverse Robotics 等。
第一作者：Zebin Xing
论文出处：arXiv:2610.28613 ｜ 发表状态：预印本，尚未确认正式接收。

它解决什么问题？

现在的视频世界模型已经能生成比较逼真的未来画面。但对于机器人来说，画面看起来正确，不代表物理接触真的正确——比如机器人拧瓶盖，模型可能生成一段看起来很自然的视频，但实际接触力可能完全不合理。

Physical Canvas 把视觉、触觉和机器人动作放到统一的生成模型中。它不仅预测物体怎么移动，还预测接触过程中触觉传感器会发生什么变化。

实验结果：在四项真实机器人操作任务中，研究报告：世界模型预测与真实任务成功率之间的相关性明显提高；利用世界模型中的模拟交互继续训练后，π₀.₅ 的平均真实任务成功率从 59.1% 提升至 70.8%。arXiv

影响分析：这是世界模型从视觉预测走向物理交互预测的重要研究方向。未来机器人可能先在包含视觉和触觉反馈的虚拟环境中学习，再把策略部署到真实设备。
项目主页：Physical Canvas
06 ｜ 期刊接收

机器人控制：把强化学习与传统迭代学习控制结合

RILC ｜ 重要性：★★★★☆

论文：Reinforced Iterative Learning Control for Elastic Joint Arms

作者：Yuri De Santis、Michele Pierallini、Franco Angelini、Manolo Garabini。
出处：arXiv:2610.28329 ｜ 发表期刊：Control Engineering Practice ｜ 发表状态：已接收。
学术认可度：较高。Control Engineering Practice 是控制工程领域具有专业认可度的同行评审期刊，但不宜直接与机器人领域的 T-RO、IJRR 等顶级期刊等同。

它解决什么问题？

传统迭代学习控制（ILC）能够让机器人通过重复执行一条轨迹，不断减小跟踪误差，但换一条新轨迹后往往需要重新学习。强化学习则能够在不同轨迹之间泛化，但可能需要较多训练数据。

RILC 将两者结合：强化学习负责给新轨迹提供一个较好的初始控制策略，ILC 负责通过重复执行继续提高精度。研究还给出了特定条件下的稳定性和收敛性分析，并在具有弹性关节的四自由度机械臂上进行了验证。arXiv

影响分析：这项研究没有 VLA 那么引人注目，但非常贴近实际控制问题。机器人最终需要执行准确、稳定的运动。将学习方法与有理论保证的传统控制方法结合，是值得持续关注的路线。

07 ｜ 产品发布

Anthropic 发布 Claude Duet：AI Agent 开始主动找人，而不是等人提问

10 月 21 日 ｜ 重要性：★★★★★
公司：Anthropic ｜ 官方来源：Introducing Claude Duet

具体发布了什么？

Claude Duet 是一款主动式 AI Agent，使用 Claude Opus 5.5 模型。与传统聊天机器人不同，它不需要每次都等待用户提出具体问题：它可以连接工作应用，持续关注任务变化，并主动汇报重要信息。

例如：早上自动整理工作安排，发现会议冲突时提醒用户；收到需要处理的邮件时准备回复；或者在用户离开电脑后继续完成已经安排的任务。Duet 有自己的云端运行环境，可以在后台使用浏览器和连接的应用。

安全机制：Anthropic 特别强调，Duet 在发送消息、付款、签署文件或删除内容前，需要用户确认。这说明 Agent 的产品设计正在从"能不能完成任务"，转向"哪些事情可以自主完成，哪些必须交给人决定"。

目前状态：研究预览阶段，首先面向美国 Pro 和 Max 用户开放候补申请，并非全面上线。Claude
影响分析：AI Agent 正从被动执行工具转向长期工作的数字助手。未来的竞争重点可能是任务完成率、长期记忆、权限管理和跨应用协作，而不只是基础模型的推理分数。
08 ｜ 产业合作

OpenAI 与 Google Cloud 合作：大模型竞争对手开始共享销售渠道

10 月 21 日 ｜ 重要性：★★★★★
公司：OpenAI、Google
官方来源：OpenAI 公告 ｜ Google Cloud 公告

双方宣布，OpenAI 的前沿模型和 Codex Agent 工作流程将进入 Google Cloud 的 Model Garden。企业可以通过 Google Cloud 使用 GPT-Astra、GPT-6.1 Sol 和 GPT-6 Luna 等模型。

为什么值得关注？

过去，大模型公司不仅竞争模型性能，也竞争云计算平台和企业客户。现在，Google 一方面开发 Gemini，另一方面也开始提供 OpenAI 的模型。企业可以在同一个平台上选择不同公司的模型，而不必为每种模型单独建设基础设施。

当前进展：Google 表示，相关模型正在向部分企业客户开放私人预览。企业可以利用 Google Cloud 的访问控制、数据治理和审计功能管理模型调用。OpenAI 模型未来还计划进入 Google Antigravity 等产品。Google Cloud

影响分析：大模型正在从单独销售的 API，逐渐变成企业云平台中的标准化能力。长期来看，企业可能更关注不同模型如何协作、成本如何控制，以及如何将模型整合进自己的 Agent 系统。
09 ｜ 架构发布

NVIDIA OpenShell：给 AI Agent 建立独立的安全运行环境

10 月 21 日 ｜ 重要性：★★★★★
公司：NVIDIA ｜ 官方来源：NVIDIA OpenShell 公告

它解决什么问题？

假设一个 Agent 需要操作企业数据库——它可能需要读取客户信息、修改订单、调用内部系统。问题是：如果 Agent 理解错了任务，或者受到恶意网页内容影响，可能执行超出授权范围的操作。

NVIDIA 的 OpenShell Reference Architecture 希望在基础设施层面限制这些风险。它将三类计算能力结合：

硬件或软件主要作用
Vera Rubin运行大模型推理
Vera CPU执行 Agent 工作流程和工具调用
BlueField-4 + Sentry监测行为并执行安全策略
OpenShell 软件提供隔离、权限和运行时管理

参与相关合作的企业包括 AWS、Anthropic、Microsoft、OpenAI、Google Cloud 等。不同公司的参与方式并不完全相同。NVIDIA Newsroom

为什么重要：以前 Agent 安全主要依赖模型本身的规则和软件权限。NVIDIA 现在尝试把安全机制进一步放到计算基础设施中——不仅要求 Agent 遵守规则，还要让底层系统有能力限制它的行为。
影响分析：随着 Agent 获得更多执行权限，独立监控和权限隔离会越来越重要。这一技术路线也可能用于工业机器人和 Physical AI 系统，但硬件隔离并不能替代机器人本身的功能安全验证。

五、本期综合判断

今天有三条技术主线特别值得关注。

第一，世界模型开始真正影响机器人训练效率。 SuperMimic 说明，世界模型不仅可以预测未来，还可以直接帮助机器人更高效地学习动作。Physical Canvas 则尝试解决另一个问题：世界模型生成的物理交互是否可信。前者关注训练速度，后者关注训练环境的真实性。这两项能力如果能够结合，可能进一步降低机器人学习对真实硬件实验的依赖。

第二，机器人基础模型正在走向更完整的能力体系。 UniWALM 把动作、语言和世界预测结合起来；AdaDex 则把人类示范和强化学习结合起来，让机器人技能既有合理的操作方式，又能够适应环境变化。这说明机器人研究正在同时推进两个方向：一个方向是让模型更通用，另一个方向是让模型学到的动作更可靠。两者并不矛盾。

第三，NVIDIA 正在扩大 Physical AI 平台的覆盖范围。 今天 NVIDIA 发布的 Isaac Lab 3.0、Isaac OS、机器人参考平台和 OpenShell，覆盖了从训练到部署、再到安全管理的多个环节——训练机器人 → 在仿真中验证 → 部署到真实硬件 → 管理运行与安全。NVIDIA 希望在这条链条中提供尽可能完整的基础设施。不过，机器人企业是否会普遍采用同一套技术体系，还取决于性能、成本、开放程度以及与现有工业系统的兼容性。
