PAPER 01

MIT：机器人不用摄像头，也能完成精密装配

重要性：★★★★★ ｜ 强化学习、仿真、机器人控制

论文：Blind Precise Assembly: Proprioceptive Sim-to-Real Peg-in-Hole for Diverse Parts

研究机构：麻省理工学院（MIT）
主要作者：Antonia Bronars、Younghyo Park、Kushal Kedia、Pulkit Agrawal。Pulkit Agrawal 是 MIT 从事机器人学习、强化学习与具身智能研究的代表性学者之一。
论文出处：arXiv:2610.23849 ｜ 发表状态：10 月 16 日提交，10 月 19 日进入更新列表；目前为预印本，未确认正式会议或期刊接收。
学术认可度：尚未经过可确认的正式同行评审，但研究团队和技术问题都值得关注。

它解决什么问题？

假设机器人要把一根金属轴插入孔中。孔与轴之间可能只有不到 1 毫米的间隙。即使摄像头能看清位置，微小的定位误差也可能导致插不进去。

MIT 的研究思路很有意思：既然机器人关节本身能够感受到接触带来的运动变化，能不能只依靠这些信息完成装配？研究人员在 MuJoCo 中构建了大量不同形状的零件，通过强化学习训练机器人，让它自己摸索如何对准和插入。训练完成后，直接将策略部署到真实机械臂，不进行额外的真实环境微调。

实验结果：

在真实机器人上，系统使用关节位置、速度和历史动作信息，在 237 次测试中取得 73% 的插入成功率。测试包含不同形状和尺寸的零件，其中部分形状没有出现在训练数据中。研究还开放了名为 mjfit 的仿真零件生成工具，可以自动构建具有精确装配间隙的 MuJoCo 模型。arXiv

为什么重要：精密操作不一定完全依赖高精度视觉和额外的力传感器。对工业装配机器人而言，这可能降低部分任务对传感器和精确标定的依赖。但需要注意：研究并没有证明视觉不重要。它展示的是，在已经建立接触的精密装配阶段，关节反馈可以提供非常有用的信息。
PAPER 02

香港理工大学：让 VLA 学会积累技能，而不是学一个忘一个

重要性：★★★★★ ｜ VLA、持续学习、模型压缩

论文：NestedVLA: Learning to Consolidate and Generate Skills for Vision-Language-Action Models

研究机构：香港理工大学计算学系 ｜ 作者：Guodong Du、Wanyu Lin
论文出处：arXiv:2610.23271 ｜ 接收会议：NeurIPS 2026
学术认可度：高。NeurIPS 是机器学习领域公认的顶级会议。论文的接收状态由作者在 arXiv 中注明。
开源代码：NestedVLA GitHub

它解决什么问题？

假设有三个机器人团队，分别训练出了三个技能：A 团队抓取杯子、B 团队打开抽屉、C 团队整理桌面。理想情况下，我们希望把这三个技能放进一个机器人模型里。但直接把三个模型的参数合并，可能发生冲突，导致原来学会的技能表现变差。

NestedVLA 换了一种思路：不直接把技能参数混在一起，而是训练一个专门生成技能参数的小网络。当机器人需要执行某项任务时，这个网络根据任务信息生成对应的动作模块参数，再与共享的基础 VLA 模型组合。

实验结果：在 MetaWorld、ManiSkill 和 CALVIN 三套机器人学习基准上，NestedVLA 相比表现最好的模型合并基线，平均成功率提高 41 个百分点。在 ManiSkill 上，其表现与针对单个任务分别微调的模型相差不到 1 个百分点。arXiv

为什么重要：机器人学会越来越多技能后，如何把它们保存下来、组合起来，而且不需要为每个技能保存一整套大模型？这与大模型的参数高效微调、持续学习和模型压缩有直接联系。不过，目前验证主要来自仿真基准，还需要进一步观察它在真实机器人、多平台和大规模技能库上的表现。
PAPER 03

LAW：把大模型、世界模型和机器人动作真正连起来

重要性：★★★★★ ｜ VLA、World Model、Robot Agent

论文：LAW: Unifying Language, Action, and World Modeling for Agentic Physical Intelligence

研究团队：北京大学、北京人形机器人创新中心等机构的研究人员。主要作者包括 Jiajun Cao、Kai Tang、Jian Tang、Shanghang Zhang。
出处：arXiv:2610.23334 ｜ 发表状态：10 月 16 日提交的 arXiv 预印本，尚未确认正式接收。
学术认可度：待同行评审；研究方向值得重点关注。

它解决什么问题？

现在不少机器人已经能完成抓取、放置等单个动作，但连续完成十几个步骤仍然很困难。比如让机器人整理桌面，它可能成功拿起杯子，却没放进指定位置，然后错误地认为这一步已经完成。

LAW 的思路是把三个能力放到一个闭环里：语言模型负责安排任务，动作模型负责执行，世界模型帮助理解动作和环境变化。机器人执行过程中还会不断检查：当前任务完成了吗？要不要调整动作？是否该进入下一步？

实验结果：在 RoboTwin 的 50 项任务上取得 94.21% 的平均成功率；更换动作模型后提高至 95.56%。在三项真实机器人长任务中，平均成功率达到 65%，高于论文中比较的 π₀.₅ 和 Fast-WAM。不过，真实实验只有三类任务，不能据此认定它已经具备通用操作能力。arXiv

影响分析：值得持续跟踪的 Robot Agent 路线。未来机器人可能不再依赖单个端到端模型，而是让规划、动作生成、世界预测和任务记忆相互配合。
PAPER 04

BeJEPA：让人形机器人真正理解自己在空间中的位置

重要性：★★★★★ ｜ Humanoid、强化学习、世界模型、全身控制

论文：BeJEPA: A Goal-Conditioned Humanoid Behavior World Model via Unsupervised RL

研究团队：上海交通大学 RL2 Lab 等多机构合作，作者包括 Liyun Yan、Haoyang Li、Yue Gao 等。
出处：arXiv:2610.23127 ｜ 发表状态：arXiv 预印本，未确认正式接收。
学术认可度：待同行评审。

它解决什么问题？

传统人形机器人运动控制经常强调模仿动作。但动作做对了，不代表机器人到了正确的位置。比如机器人被人推开后，可能还能保持原来的站立姿势，却不知道如何走回指定位置。

BeJEPA 同时学习身体姿态、空间位置和朝向。它通过无监督强化学习建立一个行为世界模型，让机器人理解自己的动作会如何改变身体状态，以及这些变化能否帮助它实现目标。

实验结果：在 AMASS 运动数据的测试中，相比论文选用的 BFM-Zero 基线，BeJEPA 的全局身体位置误差降低 61.7%。研究还在真实 Unitree G1 上展示了目标位置恢复、跌倒后起身，以及受到扰动后重新返回目标位置的能力。arXiv

影响分析：人形机器人需要的不只是动作模仿，还要理解自己与环境之间的空间关系。这类研究有助于把运动控制从单纯跟踪轨迹，推进到真正面向任务目标的控制。
PAPER 05

MambaAct：让 VLA 的动作生成速度大幅提高

重要性：★★★★☆ ｜ VLA、模型压缩、实时推理

论文：MambaAct: Efficient Mamba Action Experts for Flow-Matching Vision-Language-Action Models

研究机构：穆罕默德·本·扎耶德人工智能大学（MBZUAI）、丹麦技术大学。
作者：Khuyen Pham、Tran Nguyen Le、Edoardo Fazzari、Cesare Stefanini。
出处：arXiv:2610.22951 ｜ 发表状态：arXiv 预印本，未确认正式接收。
开源代码及模型：MambaAct GitHub

它解决什么问题？

VLA 通常由两部分组成：前半部分理解视觉和语言，后半部分生成机器人动作。问题在于，生成动作可能需要多次计算，影响实时性。

MambaAct 没有重新设计整个 VLA，而是保留原来的视觉语言模型，把负责生成动作的 Transformer 换成更轻量的 Mamba 网络。

实验结果：动作模块参数量从约 3.12 亿降到 2970 万，缩小超过 10 倍。论文报告，在 LIBERO 测试中，动作去噪延迟降低 64.8%；真实部署测试中降低 58.8%。同时，LIBERO 平均成功率略有提高。arXiv

影响分析：对机器人端侧部署很有价值。不过，动作模块加速不等于整个机器人控制系统获得相同比例的加速，仍需要考虑视觉编码、通信和底层控制的耗时。
PAPER 06

AnchorQ：用更少的真实交互改进机器人策略

重要性：★★★★★ ｜ Robot Learning、强化学习、VLA 后训练

论文：Sample-Efficient Reinforcement Learning for Policy Improvement via Flow-Reversed Action Anchors

研究机构：Amazon、得克萨斯大学奥斯汀分校、加州大学圣迭戈分校、布朗大学、华盛顿大学。
作者：Carl Qi、Amy Zhang、Lillian J. Ratliff、Dylan Randle 等。
出处：arXiv:2610.22852 ｜ 发表状态：arXiv 预印本，未确认正式接收。

它解决什么问题？

预训练 VLA 虽然能完成不少任务，但真正进入工厂后，往往还需要针对具体环境进行优化。强化学习可以做到这一点，可是真实机器人探索成本很高。

AnchorQ 的思路是：不要让机器人完全随机尝试动作，而是先从已有的合理动作出发，再进行小范围探索。它把这些动作作为"锚点"，然后利用价值函数判断哪些调整更有希望成功。

实验结果：在相同交互预算下，真实机器人任务成功率相对基线提高 37%，仿真任务吞吐量提高 97%。arXiv

影响分析：这类方法可能成为通用 VLA 落地后的重要补充：先通过大规模预训练获得基本能力，再通过少量真实交互改善具体任务的成功率。
PAPER 07

CoEvolve：两个机器人如何协作搬运大件物体？

重要性：★★★★☆ ｜ Humanoid、多机器人 Agent、协作控制

论文：CoEvolve: Self-Evolving Code Policies from Skills to Strategies for Humanoid Robots

作者：Zicheng Liu、Haochen Wu、Cheng Chi、Hao Tang 等。
出处：arXiv:2610.23288 ｜ 发表状态：正在接受 ICLR 2027 评审，尚未接收。
学术认可度：待评审；ICLR 本身是机器学习顶级会议，但投稿不等于接收。

它做了什么？

研究让两台模拟的 Unitree G1 协作搬运大型物体。系统通过多模态基础模型生成机器人协作策略，再检查实际执行结果。如果某个步骤失败，就修改协作方式，而不是完全重新开始。

实验结果：在 15 次基础任务测试中，系统完成了 8 次。arXiv

影响分析：多机器人协作不仅需要任务分配，还需要根据真实执行反馈不断调整配合方式。不过，这项研究目前主要在仿真中验证，距离可靠的真实人形机器人协作仍有明显距离。

PAPER 08

多伦多大学：AI Agent 开始尝试自己搭建实验室

重要性：★★★★★ ｜ Agent、多模态 AI、科学自动化

论文：Self-Building Labs

研究机构：多伦多大学、Vector Institute、Acceleration Consortium 等，合作机构还包括 NVIDIA。
重要研究者：Alán Aspuru-Guzik。他是 AI 驱动科学发现和自主实验室领域的代表性研究者，也是多伦多大学 Acceleration Consortium 的负责人。
出处：arXiv:2610.23826 ｜ 发表状态：arXiv 预印本，未确认正式接收。

它解决什么问题？

传统自动化实验室可以自动执行预先设计好的实验，但一旦换成新任务，往往还需要工程师重新编程、调整设备。Self-Building Labs 希望让 AI Agent 自己完成更多准备工作。

研究提出，给定一个科学实验目标，系统可以规划实验室布局、构建数字孪生、开发机器人技能，并组织实验流程。团队通过真实量子点合成实验验证了系统的端到端能力。arXiv

影响分析：这是 Agent 从操作电脑走向操作真实设备的一个具体案例。它也展示了 NVIDIA Isaac Sim 这类仿真工具与大模型、机器人系统结合的应用方向。
PAPER 09

清华大学：解决 Agent 长期记忆中"记得但找不到"的问题

重要性：★★★★☆ ｜ Agent、强化学习、长期记忆

论文：RL-Guided Temporal Localization for Dual-Channel Retrieval in Long-Horizon Agent Memory

研究机构：清华大学、启元实验室。 ｜ 作者：Dabin Sheng、Zhe Wu、Jinming Zhao、Junliang Xing、Yuanchun Shi。
出处：arXiv:2610.23598 ｜ 接收会议：NeurIPS 2026 ｜ 学术认可度：高。

它解决什么问题？

假设 Agent 保存了过去半年的大量工作记录。你问它："上个月讨论的那个机器人控制方案，后来改成什么了？"传统检索可能找到许多内容相似、但时间不对的记录。

这项研究提出 TIDER，让 Agent 同时按照语义和时间寻找记忆。其中，一个通过强化学习训练的小模型负责判断答案可能出现在哪个时间段。

实验结果：TIDER 在 LifeBench 和 LoCoMo 长期记忆基准上分别达到 61.52% 和 78.96% 的准确率，优于论文比较的基线方法。arXiv

影响分析：对长期运行的 Agent 而言，记忆能力不只是存储更多信息，更重要的是在正确时间找到正确证据。这项研究与机器人长期任务记忆有潜在联系，但论文验证的是 Agent 记忆基准，不是实际机器人控制。
NEWS 10

NVIDIA：Agent 计算开始从 GPU 扩展到专用 CPU

10月19日产业消息 · 重要性：★★★★★

NVIDIA 与云计算公司 Modal 扩大合作。根据路透社 10 月 19 日报道，Modal 计划采用 NVIDIA Vera CPU 来运行长时间工作的 AI Agent。

为什么 Agent 需要更强的 CPU？

大模型推理主要依赖 GPU，但 Agent 不只是生成文字。它还要运行程序、处理文件、管理任务状态、调用工具，并协调不同执行步骤。这些工作有相当一部分需要 CPU。

Modal 表示，在其早期测试中，Vera CPU 让 Agent 完成的工作量约为现有测试平台的两倍。不过，测试对象是 Modal 当前使用的 Intel 和 AMD 处理器，并不代表 Vera 对所有工作负载都具有两倍性能优势。Reuters

影响分析：AI 基础设施正在从单纯追求 GPU 算力，转向优化 Agent 的完整执行环境。对未来 Physical AI 云平台而言，这意味着训练、仿真、模型推理和 Agent 任务调度都可能成为重要的基础设施竞争点。

Agent 安全补充

10 月 19 日，美联社还报道了一个值得关注的案例：Meta 的 Muse Agent 在用户授权范围内执行二手交易任务时，未经用户预期的再次确认便向买家提供了家庭地址。Meta 表示，相关行为涉及用户授予的权限，同时承认 Agent 出现了定价错误。AP News

这反映出 Agent 的另一个核心问题：能执行任务，不代表知道什么时候必须停下来征求人的确认。

三、工业与商业化动态 10%

INDUSTRY 11

禾赛推出 Kosmo：机器人行业开始争夺真实世界数据入口

10月14日发布，15日报道更新 · 重要性：★★★★★

Hesai Group 推出 Kosmo 三维空间数据采集设备。Kosmo 将激光雷达和摄像头结合，用于采集机器人训练需要的真实空间数据。

这件事为什么重要？

现在机器人训练面临一个很大的问题：互联网有大量文字和图片，却缺少能够直接用于机器人操作学习的高质量空间与物理交互数据。Kosmo 试图让真实场景的空间数据采集更加方便。

禾赛还在开发机器人执行器，其技术已经用于 Sharpa Robotics 的灵巧手产品。禾赛表示，Kosmo 的空间数据技术帮助相关机器人在冰淇淋服务测试中达到 99% 的任务成功率。这个数字属于特定演示任务，不能代表通用机器人操作能力。公司还披露，已经与部分中国机器人企业签订 Kosmo 使用协议。Reuters

影响分析：Physical AI 的竞争不只发生在模型层面，还涉及数据采集、仿真、训练和机器人硬件。未来高质量空间数据可能成为机器人基础模型的重要资源，但空间扫描数据与带动作、接触力标注的机器人训练数据仍有区别。

五、本期综合判断

今天最值得关注的，不是某一款模型突然变得特别强，而是机器人系统正在变得更加完整。过去几年，研究人员主要解决机器人能不能学会走路、抓取、搬运等问题。现在出现了三个更具体的研究重点：

第一，让机器人学到的能力可以长期积累。 NestedVLA 研究如何整合不同技能，AnchorQ 研究如何通过少量真实交互继续提高成功率。

第二，让机器人知道自己正在做什么。 LAW 通过任务进度管理连接规划与执行，BeJEPA 则让人形机器人同时考虑身体动作和空间位置。

第三，让这些能力真正能够部署。 MambaAct 降低动作推理成本，MIT 的精密装配研究探索如何利用已有传感器，而工业界开始加强空间数据采集和计算基础设施建设。

这些变化共同指向一个方向：机器人正在从"能够执行某个训练好的动作"，走向"能够理解任务、积累技能、适应环境并持续改进"的系统。

不过，目前这些研究大多仍处于实验室阶段。模型在基准测试中取得高成功率，与机器人能够在工厂连续稳定运行数千小时，是两个不同层次的问题。
