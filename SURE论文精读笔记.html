PAPER NOTES · SURE

SURE 论文精读笔记

SURE: Safe Uncertainty-Aware Robot-Environment Interaction using Trajectory Optimization · arXiv:2602.06864

研究机器人与环境交互时的接触时间不确定性：通过多分支轨迹 + 汇合约束，把多种可能的接触时刻显式纳入轨迹优化，同时共享汇合后的终端轨迹、减少重复规划。笔记覆盖研究背景、核心思想、公式（1）（2）、分支数量与复杂度、两种执行方式、两个实验、贡献与局限、概念速查与自测问题。

01 论文研究背景与核心问题
1. 研究问题

SURE 研究机器人与环境交互时的接触时间不确定性。实际接触时刻可能偏离计划时刻，原因包括：

  • 物体初始位置或高度存在误差；
  • 机器人状态估计存在误差；
  • 释放动作、通信或控制过程存在延迟；
  • 实际接触与模型预测不完全一致。

接触时间变化不仅会影响接触发生的时刻，还可能改变接触前的状态、碰撞后的速度和后续运动。因此，只针对一个预定接触时刻规划轨迹，可能无法适应真实环境中的变化。

2. 为什么接触问题特殊？

这类系统具有混合动力学系统（Hybrid Dynamical System）的特点：

  • 接触前：系统遵循连续运动动力学；
  • 接触瞬间：触发接触条件，状态可能发生跳变；
  • 接触后：系统进入新的动力学模式。

接触时刻不仅是普通的时间参数，还决定了系统何时切换动力学模式。

3. 传统方法的局限

传统名义轨迹优化通常预先指定接触发生在哪个离散节点，并针对该时刻规划一条轨迹。如果真实接触时间偏离计划，机器人可能进入原轨迹没有充分考虑的状态，导致后续运动不再合适。

SURE 要解决的问题是：如何在轨迹优化阶段考虑多个可能的接触时刻，同时避免为每种情况都独立规划到终点所造成的巨大计算负担？

02 SURE 的核心思想
核心：为多个可能的接触时刻建立轨迹分支，再让这些分支在共同状态处汇合，之后共享最终轨迹。

整个结构可以分为三部分：

1. 共享的接触前轨迹。
2. 针对不同接触时刻的接触后分支。
3. 各分支汇合后的共享终端轨迹。

概念示意：

共享接触前轨迹 ├── 接触情况 i → 分支 i ──┐ ├── 接触情况 j → 分支 j ──┼── 共同状态 → 共享终端轨迹 └── 接触情况 k → 分支 k ──┘

注意：这些分支代表优化问题中需要考虑的不同可能情况，不等于运行时随机尝试多条轨迹。

SURE 的主要设计不是取消动力学模型，而是改变优化问题的结构：

  • 用分支表达接触时刻不确定性；
  • 用汇合约束减少重复规划；
  • 在鲁棒性和计算成本之间取得折中。
03 公式（1）：传统名义轨迹优化

核心：在满足动力学、接触和任务约束的前提下，寻找代价尽可能低的一条轨迹。

传统方法指定接触节点 c：

  • 接触前满足未接触条件；
  • 在节点 c 满足 g(xc) = 0；
  • 接触后通过重置映射 R 描述状态跳变；
  • 整条轨迹满足动力学和任务约束。
边界：公式（1）本身并没有问题，它能解决指定接触时刻下的轨迹优化问题。局限在于，它没有同时规划其他接触时刻下的后续运动。
04 公式（2）：SURE 的分支与汇合

公式（2）在传统轨迹结构上增加了多条接触后分支以及分支汇合约束。

1. 目标函数的直觉
总成本 = 共享轨迹成本 + 各分支成本 + 终端轨迹成本

优化器需要同时考虑共享轨迹和不同接触情况下的后续运动。

2. 关键符号
K

可能发生接触的离散节点集合

|K|

分支数量

K0

分支范围的起始节点

Ke

分支范围的末尾节点

xi,j

从可能接触节点 i 出发的第 j 个分支状态

ui,j

对应分支的控制输入

Nr

分支从起点走到共同汇合状态所经历的离散步数

d

接触判定函数空间中的半宽参数

3. 分支初始状态

概念上：

xi,0 = R(xi)

表示不同接触时刻对应不同的接触前状态，经过接触重置映射后，可能得到不同的分支起始状态。

4. 分支汇合约束
xi,Nr = xKe+1

这要求各分支在规定步数后回到共同状态。

好处：分支只需规划到共同状态；汇合后的终端轨迹只优化一次；避免每条分支都独立规划到终点。

代价：不同分支必须到达同一个状态；限制各分支独立选择后续运动的自由度；可能牺牲部分最优性，或增加优化难度。

5. 参数 d 的理解

d 表示接触判定函数空间中的半宽。只有当 g 直接表示几何距离时，d 才能直接理解为距离；如果 g 经过缩放或采用其他定义，就不能直接把 d 当成米。

即使 d 是优化变量，也不意味着它必然增大；其变化取决于目标函数和其他约束。

05 分支数量与计算复杂度
1. 分支越多有什么好处？

优化问题可以显式考虑更多候选接触节点，对离散化后的接触时间范围覆盖得更细。

2. 分支过少的风险
  • 可能不能充分代表不确定区间；
  • 候选节点之间的接触情况未必得到充分覆盖；
  • 对设计范围之外的情况不作保证。
3. 分支过多的代价

每增加一条分支，通常会增加：状态变量、控制变量、动力学约束、接触后约束、汇合约束。实际求解时间还受非线性程度、约束耦合、求解器和初始猜测等因素影响。

4. 与 Tree OCP 的比较

Tree OCP：每条分支都可以独立规划到终点，可能重复规划大量后续运动。

SURE：不同分支先汇合，汇合后共享终端轨迹，减少重复优化。

论文在小车倒立摆案例中报告，相对于所比较的 Tree OCP 方案：

06 优化结果的两种执行方式
1. Trajectory Scheduling（轨迹调度）

前提：系统能够可靠检测接触时刻，并及时切换轨迹。

流程：

1

沿共享接触前轨迹运动；

2

检测实际接触发生的时刻；

3

选择对应的接触后分支；

4

到达共同汇合状态后，使用共享终端轨迹。

优点：可以针对实际接触时刻选择相应的后续轨迹。
局限：依赖接触检测的可靠性和时效性。检测延迟或接触发生在离散节点之间，都可能影响切换效果。

2. Robust Nominal Trajectory（鲁棒名义轨迹）

前提：缺少可靠接触传感器，或者不适合运行时切换分支。

流程：

1

优化阶段仍考虑多条接触后分支；

2

从分支中选择中间分支；

3

将其作为单条参考轨迹执行。

注意：鲁棒名义轨迹不是把所有分支的控制输入简单求平均，而是选择中间分支作为参考轨迹。

优点：运行时不必根据实际接触时刻切换分支，但仍可能受益于优化阶段对接触时间不确定性的考虑。
局限：不能针对每个实际接触时刻选择专用分支；中间分支也不保证对所有情况都最优。

07 实验一：小车倒立摆撞墙后恢复平衡
1. 实验目的

测试接触时序和碰撞参数存在不确定性时，SURE 是否能够提高任务成功率。

2. 不确定性来源
  • 墙的位置变化；
  • 碰撞恢复系数变化（可粗略理解为碰撞沿法向有多"弹"）。
3. 比较方法
  • 传统名义轨迹；
  • SURE 鲁棒名义轨迹；
  • SURE 轨迹调度。
4. 成功判据
  • 在规定时间内到达目标状态；
  • 杆子最多与墙碰撞一次；
  • 杆子没有倒下；
  • 小车没有穿透墙壁。

论文在四组初始条件下进行测试，每组使用 200 个不确定性样本。

6. 结果解释

轨迹调度成功率最高，与它能根据实际接触时刻选择对应分支的设计相符。鲁棒名义轨迹也优于传统方法，说明仅在优化阶段考虑多个接触时刻，也可能改变共享的接触前轨迹，使运动方案提前为接触时间变化留出余量。

证据边界：实验支持 SURE 在论文所测试的系统、扰动范围和任务判据下提升成功率。但不能由此证明：所有机器人任务都能获得同样提升；所有未知扰动都能被覆盖；SURE 提供了形式化安全保证。
08 实验二：机械臂接住下落的鸡蛋
1. 实验系统

Unitree Z1 六自由度机械臂负责接住鸡蛋，末端安装轻质容器；Franka Panda 机械臂负责释放鸡蛋。由于缺少可靠的接触传感器，真实实验采用鲁棒名义轨迹，而不是轨迹调度。

2. 任务难点

鸡蛋初始高度和释放时序存在误差，实际接触时刻可能提前或延后。作者希望降低接触时鸡蛋与容器之间的相对速度，以减少冲击并提高接住鸡蛋的成功率。

3. 传统名义轨迹的代价函数

论文将接触时的相对速度代价与关节加速度平滑代价结合。概念结构：

接触相对速度² + wa · Σ q̈i² Δti

符号含义：

vball,c

接触时鸡蛋的速度

vee,c

接触时机械臂末端的速度

q̈i

关节加速度

Δti

节点时间间隔

wa

平滑代价权重

末端速度通过雅可比矩阵与关节速度联系：

vee,c = Jt(qc) q̇c

为什么惩罚相对速度？即使末端位置正确，如果鸡蛋和容器在接触瞬间的相对速度很大，也可能产生较大的冲击。因此相对速度是与接物质量相关的代理指标。

为什么惩罚关节加速度？如果只优化相对速度，优化器可能选择关节运动很剧烈的轨迹。加速度代价有助于提高轨迹平滑性。

注意：相对速度不等于直接测量或严格限制接触力；加速度惩罚不等于关节力矩约束；简化模型不能完整描述鸡蛋接触后的变形、反弹和破损过程。
4. SURE 如何修改目标函数？

传统方法主要优化指定接触节点的相对速度。SURE 引入共同上界 vlim，并对每个候选接触节点 i ∈ K 施加类似以下约束：

‖vee,i − vball,i‖² ≤ vlim²

目标函数试图压低 vlim，同时惩罚共享轨迹和分支轨迹中的关节加速度。

直觉：传统方法重点优化名义接触时刻；SURE 同时关注多个候选接触时刻；降低共同上界会使优化器关注候选情况中相对速度较大的情况。

这是针对已建模离散候选接触时刻的最坏情况设计，不等于对任意连续时间或任意未知扰动的保证。
5. 其他约束

论文还考虑与接物任务相关的几何约束，例如：末端容器保持水平；末端位置与鸡蛋下落路径对齐；接触前满足接触间隙条件，避免提前穿透。

论文使用 10 条分支，并将鸡蛋初始高度不确定性的半宽设置为 d = 0.20 m。

09 论文主要贡献

1. 将多个可能的接触时刻显式纳入轨迹优化，而不是只针对一个名义接触时刻规划。

2. 设计分支汇合结构，使不同接触情况的后续轨迹在共同状态汇合，从而共享最终轨迹、减少重复优化。

3. 在小车倒立摆和真实机械臂接鸡蛋任务中，验证该方法在指定不确定性条件下的有效性。

创新重点：将接触时刻分支、分支汇合与完整终端轨迹规划组合为一个优化框架，而不是声称发明了分支轨迹、鲁棒优化或接触动力学本身。
10 论文局限与未来方向

1. 不确定性范围依赖建模：如果实际接触时刻或其他扰动超出设计范围，不能直接保证优化结果仍然有效。

2. 汇合约束限制自由度：各分支需要到达共同状态，可能牺牲各自独立优化时的最优性，也可能导致某些问题难以找到可行解。

3. 仍然依赖动力学模型：接触模型、摩擦、执行器响应和状态估计误差都可能影响真实表现。

4. 不等于形式化安全证明：论文展示的是特定实验条件下的鲁棒性提升，不是对所有未知扰动的绝对安全保证。

5. 作者提出的未来研究方向：

  • 扩展到多次接触事件；
  • 利用鲁棒优化结果学习不确定性条件化策略；
  • 推广到浮动基机器人。
这些是作者提出的后续方向，不应理解为本文已经全部实现。
11 核心概念速查
1

接触时间不确定性：实际接触发生时刻与名义规划时刻不一致。

2

混合动力学系统：系统在连续运动过程中会因为接触等离散事件切换动力学模式。

3

Guard Function g(x)：接触事件的触发函数。

4

Reset Map R：描述接触瞬间状态跳变的映射。

5

Branch（分支）：对应一种可能接触时刻的后续轨迹。

6

Merging（汇合）：要求不同分支到达共同状态，以共享之后的终端轨迹。

7

Trajectory Scheduling：检测实际接触时刻后，切换到相应的后续分支。

8

Robust Nominal Trajectory：不进行运行时分支切换，而是选择中间分支作为单条参考轨迹。

9

vlim：SURE 接鸡蛋目标中，用于限制候选接触时刻相对速度的共同上界。

10

d：接触判定函数空间中的半宽；只有当 g 直接表示距离时，才能直接理解为几何距离。

12 全文结论

SURE 研究的是：当机器人与环境的接触时刻不确定时，如何在轨迹优化阶段考虑多种可能性，并避免为每一种可能性都重复规划到终点。

它通过多分支和汇合结构，将接触时间不确定性显式纳入优化，同时共享汇合后的终端轨迹。论文的仿真和真实机器人实验支持该方法在指定任务和不确定性范围内提高鲁棒性，并展示了相对于所比较 Tree OCP 方案的计算效率收益。

但 SURE 仍依赖建模假设、不确定性范围、优化可行性与控制执行效果。它不能被理解为对任意未知接触、任意机器人或任意扰动都有效的形式化安全保证。

一句话概括：SURE 的核心思想是"提前规划多种可能的接触后果，再让这些方案在共同状态汇合"，以在接触时间不确定性、轨迹性能与计算成本之间取得折中。
