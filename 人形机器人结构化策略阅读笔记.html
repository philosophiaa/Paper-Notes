PAPER READING NOTES · 第一篇

Learning Structured Policies for General Humanoid Loco-Manipulation

不要让人形机器人直接在高维动作空间里探索所有技能；先用 SBTO 把有限的人类示范变成大量物理可行的 motion，再让 Diffusion 学会生成 motion，让 RL Tracker 负责高频执行，最后用 tracker-in-the-loop 的 Post-training 缩小生成与执行之间的差距。

Shafeef Omar · Sebastian Sanokowski · Cordelia Schmid · Majid Khadiv MRM / INRIA / IAS
01 论文速览

这篇论文到底要解决什么问题？核心思路是什么？

核心问题
训练一个 generalist humanoid policy，让人形机器人能完成多种全身 loco-manipulation（边走边操作）任务。
三大困难
① 高自由度系统，action space 探索困难
② RL Tracker 不会产生多模态长时程规划
③ Diffusion 不知道具体机器人的物理可行性
核心思路
Diffusion 放 motion level（生成未来运动）
RL Tracker 放 action level（高频执行）
最后 tracker-in-the-loop Post-training 闭环优化

03 四大核心模块

拆解 pipeline 中每个关键组件的输入、输出和设计动机。

M1

SBTO 数据生成

IK 只能保证几何上可行，但人形机器人和人类在身体形态、关节结构、质量分布上差异巨大，IK 得到的轨迹可能存在 missing contact、脚穿模、接触不正确等问题。

SBTO（Sampling-Based Trajectory Optimization）从 imperfect kinematic trajectory 出发，搜索优化出物理一致、动态可行的 robot motion。
  • IK = "几何上机器人应该怎么摆？"
  • SBTO = "考虑物理后机器人真正应该怎么动？"
  • 每条 demo 生成 tube-like diversity 轨迹族
M2

Diffusion Motion Generator

不是直接预测 torque/action，而是预测未来一段 dynamically-feasible motion。

输入：当前 state + imperfect kinematic reference + goal（物体相对基座的方向）
输出：未来 n-step 的 robot motion sequence

为什么放 motion level？因为 legged robot 底层控制需要 50-100Hz+ 高频运行，大模型不适合直接在这个频率产生 action。
  • 传统 Diffusion Policy: obs → action
  • 本文: state + ref + goal → motion → tracker → action
  • Slow motion generation / Fast tracking control
M3

Generalist RL Tracker

DeepMimic-style RL tracking policy，负责把 desired motion 转换成高频 control action。

输入：当前机器人状态 + desired motion
输出：control action（关节力矩/位置目标）

关键设计：使用 sparse lookahead（1, 2, 4, 8 frames），让机器人提前知道未来动作趋势，支持多个 motion。
  • 只在 dynamically feasible motions 上训练
  • Adaptive sampling：困难片段更频繁访问
  • Reward = motion tracking + object tracking + regularization
M4

Tracker-in-the-loop Post-training

预训练 Diffusion 生成的 motion "数据层面好看"，但不一定正好是当前 tracker 最容易执行的。存在 plan-execution gap。

Post-training 让 Diffusion 生成 motion → Tracker 在 simulator 中真正 rollout → 比较生成轨迹 vs 实际执行轨迹 → 用 reward 反向微调 Diffusion。
  • Trackability reward：生成轨迹 vs 实际执行 state
  • Kinematic fidelity reward：生成轨迹 vs 原始 kinematic ref
  • Smoothness + Termination penalty
04 数据从哪里来？

只有 29 条有限的人类示范，如何扩展成足够训练的数据集？SBTO + Symmetry Augmentation 的威力。

数据集增长过程
29 条 demonstrations → SBTO 生成 tube-like diversity → Symmetry augmentation 扩大约 8 倍

关键洞察

Teleoperation data 非常昂贵，而 human motion data 相对容易获得并可以 retarget。论文的核心数据策略是：不依赖大量遥操作数据，而是从有限的人类示范出发，通过物理优化 + 对称性增强，程序化生成大规模训练数据。这是一种 "simulation-generated data" 的思路。

05 实验结果

100 episodes / setting，测试训练内、同类泛化和完全未见过的技能。

各任务成功率对比
Pick & Place 训练内/同类都 100%；Pushing 100% 但 tracking error 上升；Kicking 只有 74%
Tracking Error 对比（MPJPE, 单位：米）
越接近训练分布，tracking error 越小；OOD 技能（Kicking）tracking error 显著增大

实验结论解读

In-distribution generalization 比较成功：Pick & Place 训练内外都是 100%，说明模型对 "训练分布内、motion style 没见过" 的同类任务有不错泛化。

Out-of-distribution skill generalization 仍是主要挑战：Pushing 虽然 100% 成功，但作者自己解释这是因为 pushing 的运动 style 与训练中的 pick-and-place 有相似性。而 Kicking（接触动力学完全不同）成功率掉到 74%，tracking error 大幅上升——真正不同的 skill 仍然是难点。

06 三大核心贡献

这篇论文最重要的三个贡献点。

CONTRIBUTION 01

Structured Generalist Pipeline

提出了一个结构化的通用 pipeline：从不完美的 kinematic demonstrations 出发，经过 dynamically feasible motion 转换，再由 Diffusion 生成 motion、Generalist Tracker 执行 action。把 motion generation 和 low-level control 解耦。

CONTRIBUTION 02

数据生成方法

仅用有限 demonstrations，通过 SBTO 生成 feasible trajectories + symmetry augmentation（镜像对称 + 90° 旋转），将数据集有效扩大约 8 倍。不依赖昂贵的 teleoperation，而是 simulation-generated data。

CONTRIBUTION 03

Diffusion Post-training

把 tracking controller 放进 Diffusion 的训练闭环：Diffusion → Tracker → Simulator → Reward → Diffusion。目的是缩小 "生成出来的 motion" 和 "机器人真正能执行的 motion" 之间的 plan-execution gap。

07 关键词速查

读这篇论文必须理解的核心术语。

Loco-Manipulation
locomotion + manipulation = 一边移动身体，一边与物体交互
Retargeting
把 human motion 转成 robot motion 的过程
IK
Inverse Kinematics，给定目标姿态，求 robot joint configuration
SBTO
Sampling-Based Trajectory Optimization，从 imperfect kinematic trajectory 中搜索动态可行轨迹
Kinematic vs Dynamically Feasible
前者是几何/关节层面可实现；后者是考虑动力学、接触等物理约束后仍可执行
Diffusion (in this paper)
学习多模态 motion distribution，生成未来一段 motion sequence，而不是直接产生 action
Tracking Policy
把 desired motion 转换成高频 control action 的 RL controller
Post-training
预训练之后，用实际 rollout + reward 继续优化生成模型
Trackability
生成的 motion 是否容易被实际 tracker 执行的程度
