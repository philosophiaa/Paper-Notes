# PD 控制伪代码
q = data.qpos[7:]    # 关节角度（跳过 floating base）
dq = data.qvel[6:]  # 关节速度

tau = Kp * (q_target - q) - Kd * dq
data.ctrl[:] = tau
mujoco.mj_step(model, data)
viewer.sync()    # 必须！否则画面不更新
05 常见问题排查
scene.xml 找不到？
运行目录不对。用 pwd 和 ls 确认当前目录在 unitree_h1/ 下面，再运行脚本。
git clone 下载 Menagerie 失败？
GitHub 连接问题。直接网页下载 ZIP 解压，比 git clone 更稳。
Viewer 启动报错 "launch_passive requires mjpython"？
Mac Apple Silicon 上 MuJoCo Viewer 不能直接用 python 跑。用 mjpython xxx.py 运行，而不是 python xxx.py。
data.qpos 变了但 Viewer 画面不动？
launch_passive 模式需要手动同步。每次 mj_step() 之后调用 viewer.sync()，画面才会更新。
